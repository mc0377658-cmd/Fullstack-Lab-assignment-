# Experiment 9 — REST Product CRUD
Run `npm install` and `npm start`. Use Postman or curl with JSON requests.
- GET `/products` and `/products/:id`
- POST `/products` with `{ "name":"Pen", "price":10, "description":"Blue pen" }`
- PUT `/products/:id` with fields to update
- DELETE `/products/:id`
Data is in memory and resets when the server restarts.
